# Project Brief

Purpose:
- Sesame 是一个跨平台桌面文本编辑器与文件查看器，主打轻量：打开快、占用小、支持大文件与多编码。
- 目标用户是需要随手查看或小改文本、代码、配置文件的开发者，不希望为此启动一个重型 IDE。

Current direction:
- 计划内功能全部完成并实机验证：骨架、Rust 文件读写与语言/编码识别、CodeMirror 编辑器、多标签页、欢迎页、MVP 打磨、进阶特性、二期扩展。
- 已实测可用：打开文件（对话框/拖拽/命令行/右键关联）、语法高亮、多标签切换与拖拽排序、侧栏、设置、亮暗主题、快捷键面板、Markdown 预览（DOMPurify 净化）、中文查找替换、大文件分块加载与保存、后台深休眠、图片查看、会话恢复、自动保存、草稿备份、关闭确认。
- 界面规范集中在 `docs/design/design.md`，后续所有外观改动以该文件为准。

System shape:
- Tauri 2 桌面壳 + 纯 Svelte 5 + Vite 单页前端（不用 SvelteKit，无路由与 SSR）。
- 样式为 Tailwind CSS v4，CSS-first 配置；组件基于 shadcn-svelte 与 bits-ui。
- 编辑器为 CodeMirror 6，语言包与 Markdown 预览均懒加载。
- 标签页有两种内容类型：`text`（CodeMirror）与 `image`（图片查看器）。
- 编码策略：新文件 UTF-8；打开时探测（BOM → UTF-8 → GBK），保存按原编码写回。不自研编解码。
- 大文件（>5 MB）只加载前缀，保存时由 Rust 把磁盘上的尾部拼回，无需读进内存。
- 保存分三层：用户主动保存 → 自动保存（可选，写回原文件，仅对有路径的标签）→ 草稿备份（始终开启，写应用数据目录，任何标签都适用）。
- 所有保存走原子写入（临时文件 + fsync + rename）；保存前复核外部修改指纹，冲突时给「覆盖磁盘 / 加载磁盘 / 另存为」三个出口；保存成功后更新基线。
- 持久化分四份，互不干扰：设置走 `tauri-plugin-store`；最近文件、会话、草稿各由 Rust 侧单独存为 `recent.json` / `session.json` / `drafts/*.json`。
- 字体可分别设置界面字体与编辑器字体；两者默认都「跟随系统默认」，但回落到不同的内置栈（界面用无衬线，编辑器用等宽）。行号栏跟随编辑器字体。
- 强调色有 4 套可切换（indigo 默认 / pine / rose / amber），每套是完整 10 级 `--brand-*` 色阶，通过 `<html data-accent>` 切换。
- 操作反馈用**标题栏中央的状态提示**（`layout/StatusLine.svelte` + `state/status.svelte.ts`），不用 toast：图标 + 一行短文案，按语气分档自动消失（2.2s / 2.6s / 4s / 6s）。标题栏中央不再显示文件名（标签栏已有）。需要用户**决策**的事仍走原生 `message()` 对话框。`svelte-sonner` 依赖已移除。
- 二进制安全：编码探测兜底会判定「是不是文本」，非图片二进制（exe/zip/db）标记为 `binary`、编辑器只读、Rust 侧拒绝写入。导航守卫默认拒绝一切外部导航，Markdown 外链交给系统浏览器。
- Rust 端按 `commands` / `core` / `model` 分层；路径规范化、编码转换、语言识别、磁盘 IO 均在 Rust 侧完成，写操作走 `spawn_blocking`，前端只传字符串。
- 界面布局为标题栏 + 标签栏 + 编辑区，左侧栏默认折叠（Ctrl+B 展开）。

- 实机验证覆盖：打开文件、语法高亮、多标签与拖拽、侧栏、设置、字体设置、强调色切换与持久化、亮暗主题、快捷键面板、Markdown 预览与 XSS 拦截、查找替换、大文件分块加载与保存（90000 行文件保存后字节完全一致）、深休眠往返、图片查看、会话恢复、自动保存（防抖与关闭冲刷）、草稿备份（未命名内容关窗口后重启完整恢复；保存后草稿被清除）、关闭确认三按钮。

- 界面形状验收：标题栏状态提示在真实应用里实测（「✓ 已保存」绿色显示于标题栏中央，约 2.2s 后自动消失，标题栏恢复干净）；浏览器查找栏已关闭（Ctrl+F 不再弹 WebView2 的原生查找栏）。
