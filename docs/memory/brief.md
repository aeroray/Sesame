# Project Brief

Purpose:
- Sesame 是一个桌面文本编辑器与文件查看器，主打轻量：打开快、占用小、支持大文件与多编码。
- 目标用户是需要随手查看或小改文本、代码、配置文件的开发者，不希望为此启动一个重型 IDE。
- **只支持 Windows 与 macOS**，界面语言为简体中文与英文。

Current direction:
- 计划内功能全部完成并实机验证：骨架、Rust 文件读写与语言/编码识别、CodeMirror 编辑器、多标签页、欢迎页、MVP 打磨、进阶特性、二期扩展、国际化。
- 已实测可用：打开文件（对话框/拖拽/命令行/右键关联）、语法高亮、多标签切换与拖拽排序、侧栏、设置、亮暗主题、快捷键面板、Markdown 预览（DOMPurify 净化）、查找替换、大文件分块加载与保存、后台深休眠、图片查看、会话恢复、自动保存、草稿备份、关闭确认、双语界面、单实例、窗口状态记忆、手动指定编码、重开已关闭标签、缩进参考线。
- 界面规范集中在 `docs/design/design.md`，后续所有外观改动以该文件为准。

System shape:
- Tauri 2 桌面壳 + 纯 Svelte 5 + Vite 单页前端（不用 SvelteKit，无路由与 SSR）。
- 样式为 Tailwind CSS v4，CSS-first 配置；组件基于 shadcn-svelte 与 bits-ui。
- 编辑器为 CodeMirror 6，语言包与 Markdown 预览均懒加载。
- 标签页有两种内容类型：`text`（CodeMirror）与 `image`（图片查看器）。
- 国际化：自建类型化字典（`lib/i18n/`），**不引框架**。英文那份是结构来源，中文那份标注为同一类型，漏译在 svelte-check 阶段报错。默认跟随系统语言。语言状态在 `locale.svelte.ts`（runes 只能在 `.svelte.ts` 里）。
- 平台判定集中在 `utils/platform.ts`，返回 `'windows' | 'macos'` 两值。
- 编码策略：新文件 UTF-8；打开时探测（BOM → UTF-8 → GBK），保存按原编码写回。不自研编解码。**探测误判时用户可点状态栏的编码手动纠正**（`decode_as`）。
- 大文件（>5 MB）只加载前缀，保存时由 Rust 把磁盘上的尾部拼回，无需读进内存。
- 保存分三层：用户主动保存 → 自动保存（可选，写回原文件，仅对有路径的标签）→ 草稿备份（始终开启，写应用数据目录，任何标签都适用）。
- 所有保存走原子写入（临时文件 + fsync + rename）；保存前复核外部修改指纹，冲突时给「覆盖磁盘 / 加载磁盘 / 另存为」三个出口；保存成功后更新基线。
- 持久化分四份，互不干扰：设置走 `tauri-plugin-store`；最近文件、会话、草稿各由 Rust 侧单独存为 `recent.json` / `session.json` / `drafts/*.json`。
- **单实例**（`tauri-plugin-single-instance`，必须第一个注册）：再次打开文件时复用已有窗口，第二个实例只把路径 emit 给前端。**窗口状态**由 `tauri-plugin-window-state` 记忆。
- 字体可分别设置界面字体与编辑器字体；两者默认都「跟随系统默认」，但回落到不同的内置栈（界面用无衬线，编辑器用等宽）。行号栏跟随编辑器字体。
- 强调色有 4 套可切换（indigo 默认 / pine / rose / amber），每套是完整 10 级 `--brand-*` 色阶，通过 `<html data-accent>` 切换。
- 操作反馈用**标题栏中央的状态提示**（`layout/StatusLine.svelte` + `state/status.svelte.ts`），不用 toast：图标 + 一行短文案，按语气分档自动消失（2.2s / 2.6s / 4s / 6s）。标题栏中央不再显示文件名（标签栏已有）。需要用户**决策**的事仍走原生 `message()` 对话框。`svelte-sonner` 依赖已移除。
- 二进制安全：编码探测兜底会判定「是不是文本」，非图片二进制（exe/zip/db）标记为 `binary`、编辑器只读、Rust 侧拒绝写入。导航守卫默认拒绝一切外部导航，Markdown 外链交给系统浏览器。
- 缩进参考线用 `ViewPlugin` + 两层背景渐变（`editor/indent-guides.ts`），只处理视口内的行。
- 日志统一走 `utils/log.ts`（带 scope、开发环境开关），**日志文案不进 i18n 字典**。
- Rust 端按 `commands` / `core` / `model` 分层；路径规范化、编码转换、语言识别、磁盘 IO 均在 Rust 侧完成，写操作走 `spawn_blocking`，前端只传字符串。
- 界面布局为标题栏 + 标签栏 + 编辑区，左侧栏默认折叠（Ctrl+B 展开）。

Verification:
- Rust 单测 61 项通过（编码探测与二进制判定、**手动指定编码与 label 往返**、语言映射、路径规范化、内容嗅探、图片类型、会话序列化、草稿 id 过滤、原子写入、大文件两次保存不重复）。
- `svelte-check` 零错误；首屏 JS 约 277 KB（gzip），CSS 约 73 KB，语言包与预览各自独立分块。
- 实机验证覆盖：打开文件、语法高亮、多标签与拖拽、侧栏、设置、字体设置、强调色切换与持久化、亮暗主题、快捷键面板、Markdown 预览与 XSS 拦截、查找替换、大文件分块加载与保存（90000 行文件保存后字节完全一致）、深休眠往返、图片查看、会话恢复、自动保存（防抖与关闭冲刷）、草稿备份（未命名内容关窗口后重启完整恢复；保存后草稿被清除）、关闭确认三按钮。
- 保存策略验收：GBK 文件改字保存后仍是 GBK 且 CRLF 保留；外部改同一文件后保存弹出冲突提示且磁盘文件未被覆盖；强杀进程后草稿保留并在下次启动自动还原（内容与脏标记都正确）；**12 万行大文件连续保存两次后行数与内容均正确**（修复了每存一次内容就重复一截的缺陷）；**MZ 开头的二进制文件打开后编辑器只读、状态栏提示「二进制文件 · 不可编辑保存」、磁盘文件字节未被改动**。
- 界面形状验收：标题栏状态提示在真实应用里实测（「✓ 已保存」绿色显示于标题栏中央，约 2.2s 后自动消失，标题栏恢复干净）；浏览器查找栏已关闭（Ctrl+F 不再弹 WebView2 的原生查找栏）。
- 国际化验收：**实测把 `language` 设为 `en` 后整个界面切换为英文**（菜单、状态栏、快捷键提示全部生效，中文只剩代码注释）；菜单项英文文案不再折行。
- 缩进参考线验收：用 CDP 读真实计算样式确认——4ch 缩进得到 `background-size: 28px` + `no-repeat`，8ch 缩进的行正确出现两条线（修复了「渐变铺满整行、每 2 个字符一条」的缺陷）。
- 平台：Windows 实测；macOS 预期可用但**未在真机验证**（README 已如实标注）。
