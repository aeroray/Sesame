# Sesame v1.0.0

首个公开版本。Windows 与 macOS 安装包见下方 Assets。

## 这是什么

一个打开即用的轻量文本编辑器与文件查看器。不做 IDE 的事——
不打项目索引、不弹欢迎向导、不问你要打开哪个文件夹，
双击文件就能看、能改、能存。

## 主要能力

- **大文件**：超过 5 MB 按 1 MB 分块加载；保存时把未加载的尾部
  从磁盘流式拼回，不整份读进内存。
- **编码保真**：打开时探测编码（BOM → 严格 UTF-8 → GBK），
  保存时按原样写回，换行风格与 BOM 一并保留。探测不可能全对，
  点状态栏上的编码即可换个编码重新打开。
- **不丢改动**：原子写入、外部修改检测、可选的自动保存，
  以及始终开启的草稿备份（未命名标签也覆盖）。
- **图片查看**：Ctrl＋滚轮缩放、空格＋拖动平移、旋转与翻转。
- **Markdown 预览**：净化后渲染，外链交给系统浏览器。

## 安装

**Windows**：下载 `Sesame_1.0.0_x64-setup.exe` 运行。
安装时可勾选把 Sesame 注册为常见文本与图片格式的默认打开方式。

**macOS（Apple Silicon）**：下载 `Sesame_1.0.0_aarch64.dmg`，
把 Sesame 拖进「应用程序」。

> 当前安装包**未做 Apple 签名与公证**。首次打开请在 Finder 里
> 右键选择「打开」，或执行：
>
> ```bash
> xattr -rd com.apple.quarantine /Applications/Sesame.app
> ```
>
> 这只移除本机的隔离标记，不代表应用已通过 Apple 验证。

## 自动更新

Windows 与 macOS 都支持应用内更新：启动后会静默检查一次，
有新版本时在「设置 → 关于」里显示。更新包带 minisign 签名，
签名不符会被拒绝安装。

## 已知限制

- 只支持 Windows 与 macOS，不提供 Linux 版本。
- macOS 版尚未在真机上充分验证（主要差异在标题栏与 Cmd 键处理）。
- 暂不发布到 Mac App Store。
